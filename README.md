# autoPack

Telegram-бот, который собирает стикерпаки из того, что ты ему кидаешь, плюс мини-апп для редактирования наборов.

## Что умеет

**Бот**
- `/new Название` → кидаешь стикеры (можно пересылать пачкой), фотки или картинки файлом → они летят в набор. Набор создаётся с первого стикера.
- Эмодзи берётся из исходного стикера; у картинок — первое слово подписи (например, `🔥`), иначе `DEFAULT_EMOJI`.
- `/packs` — список наборов, выбрать активный (куда добавлять).
- `/stop` — перестать добавлять. Стикеры без активного набора падают во «Входящие».
- `/copy` ответом на стикер (или кнопка под подсказкой) — скопировать весь чужой набор себе.
- Подтверждает реакцией 👍 (добавлено) / 👀 (во входящие), а не спамит сообщениями.

**Мини-апп** (кнопка меню «Наборы» или `/app`)
- Список наборов с обложками, создание нового из входящих.
- Внутри набора: перетаскивание для смены порядка, «в начало / в конец», переименование, эмодзи у каждого стикера (до 20), удаление стикера и всего набора, ссылка на набор.
- Добавление из входящих или загрузкой файла (картинки сами ужимаются до 512px; `.tgs` / `.webm` грузятся как есть).
- Переключатель «бот добавляет сюда».
- Анимированные (`.tgs`) стикеры проигрываются через lottie, видео — через `<video>` (на iOS показывается превью).

**Главное меню** (`/start`): Упаковщик стикер-паков, Спамблок, Инфа, Заказ. У каждого экрана свой текст и баннер, меняются в админке → «Меню». Готовый пост можно просто переслать боту («Взять из сообщения»), и он сохранится с премиум-эмодзи и форматированием.

**Оформление экранов** — Rich Messages (Bot API 10.2+), как посты BLUEBLACK: заголовки в плашках, плашки с текстом по центру, баннер посреди поста. Разметка текста экрана: `# Заголовок`, `[[ … ]]` — плашка, `[banner]`, `---`, `> цитата`, `~ подпись`. Если Telegram не примет rich-сообщение, бот отправит обычное. Иконки в сообщениях бота — iOS-набор (`tgmacicons`), свои эмодзи — редкими акцентами `{xm}`, заголовки `{big:СЛОВО}` — буквами-эмодзи.

**Спамблок**: всё, что юзер пишет в этом режиме (текст, фото, стикеры, голосовые, видео, файлы), падает админу в мини-апку → «Чаты». Админ отвечает оттуда текстом или фото, ответ приходит юзеру от бота. О новом диалоге бот пишет админу уведомление.

**Темы мини-аппа**: как в Telegram, светлая, тёмная, полночь, неон, закат, мята, монохром. Кнопка с палитрой на главной; тема синхронизируется между устройствами через облако Telegram.

**Монетизация (Telegram Stars)**
- Бесплатно к названию набора всегда дописывается подпись (по умолчанию ` || @stikcerpack_bot by @xmapket`), поэтому на само название остаётся меньше символов.
- Доступ к набору покупается за звёзды (по умолчанию 15 ⭐ за набор): подпись уходит, название до 64 символов, ссылку на набор можно поменять на свою.
- Смена ссылки: Telegram не умеет переименовывать набор, поэтому бот пересоздаёт его под новым именем со всеми стикерами, порядком и эмодзи, а старый удаляет.
- Если подпись убрать руками через @Stickers, у неоплаченного набора бот вернёт её при следующем открытии.

**Админка** (шестерёнка в мини-аппе или `/admin`, только для `ADMIN_IDS`)
- Статистика: пользователи, заблокировавшие, наборы, оплаты, заработанные звёзды; список оплат с кнопкой возврата звёзд.
- Продажи: цена и текст подписи.
- Рассылка: пост (HTML Telegram, картинка, кнопка-ссылка), день недели и час (по `TIMEZONE`), «тест себе», «разослать сейчас», итоги последней рассылки. Кто заблокировал бота, тот помечается и дальше не получает.
- Оформление: набор премиум-эмодзи для иконок (по умолчанию `tgmacicons`), иконки подбираются автоматически по смыслу, любую можно заменить руками. Премиум-эмодзи в сообщениях бота Telegram показывает, только если у владельца бота есть Premium (или у бота юзернейм с Fragment); иначе бот сам откатывается на обычные эмодзи.

Админы пользуются всем бесплатно. Свой ID можно узнать командой `/id`.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), возьми токен.
2. Нужен публичный HTTPS-адрес до порта `8080` (свой домен за nginx/Caddy, или на время разработки `cloudflared tunnel --url http://localhost:8080` / ngrok).
3. `cp .env.example .env` и заполни `BOT_TOKEN` и `WEBAPP_URL`.
4. Запусти:

   ```bash
   docker compose up -d --build
   ```

   или без докера:

   ```bash
   python -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python -m app.main
   ```

**Windows, в один клик:** заполни в `.env` только `BOT_TOKEN`, установи `cloudflared` (`winget install --id Cloudflare.cloudflared`) и дважды кликни `start.bat`. Он сам поставит зависимости при первом запуске, поднимет туннель, впишет свежий адрес в `WEBAPP_URL` и запустит бота. Закрыл окно — всё остановилось.

При старте бот сам выставляет команды и кнопку меню с мини-аппом. Бот работает на long polling, вебхук не нужен — HTTPS нужен только для мини-аппа.

## На VPS (24/7, без туннеля)

Нужен сервер на Ubuntu 22.04/24.04 (хватит 1 CPU / 1 ГБ). Закинь на него папки `app`, `webapp`, `deploy`, файлы `requirements.txt`, `.env` и (если есть) папку `data`, потом в папке бота:

```bash
sudo bash deploy/install.sh
```

Скрипт ставит Python и Caddy, поднимает бота как сервис (сам перезапускается и стартует после ребута) и выдаёт HTTPS-адрес вида `https://1-2-3-4.sslip.io/` без покупки домена. Со своим доменом: `sudo DOMAIN=bot.example.com bash deploy/install.sh`. Обновление после замены `app`/`webapp`: `sudo bash deploy/update.sh`.

## Устройство

- `app/service.py` — вся работа с Bot API (создание/добавление/порядок/эмодзи/удаление, ретраи на флуд-лимиты). Используется и ботом, и API.
- `app/bot.py` — хендлеры aiogram 3.
- `app/web.py` — aiohttp API для мини-аппа. Авторизация — проверка подписи `initData` от Telegram. Картинки стикеров отдаются через подписанный прокси `/f/<file_id>`.
- `app/db.py` — SQLite: наборы, активный набор юзера, входящие, полный список эмодзи (Bot API отдаёт только один), оплаты, настройки. Старая база мигрирует сама.
- `app/broadcast.py` — еженедельная рассылка.
- `app/icons.py` — иконки из набора премиум-эмодзи и откат на обычные, если Telegram их не пускает.
- `webapp/` — сам мини-апп, ванильный JS + SortableJS + lottie.

Содержимое наборов не дублируется в базе — оно каждый раз читается из Telegram (`getStickerSet`), так что правки через @Stickers тоже видны. Если набор удалили снаружи, бот его забывает.

## Ограничения Telegram

- В наборе максимум 120 стикеров, название до 64 символов.
- Бот видит только наборы, которые создал сам.
- Гифки/видео из чата не конвертируются — нужен готовый `.webm` по требованиям Telegram.
