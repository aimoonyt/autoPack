# autoPack

Telegram-бот, который собирает стикерпаки из того, что ты ему кидаешь, плюс мини-апп для редактирования наборов.

## Что умеет

**Бот**
- `/new Название` → кидаешь стикеры (можно пересылать пачкой), фотки или картинки файлом → они летят в набор. Набор создаётся с первого стикера.
- Эмодзи берётся из исходного стикера; у картинок — первое слово подписи (например, `🔥`), иначе `DEFAULT_EMOJI`.
- `/packs` — список наборов, выбрать активный (куда добавлять).
- `/stop` — перестать добавлять. Стикеры без активного набора падают во «Входящие».
- `/copy` ответом на стикер (или кнопка под подсказкой) — скопировать весь чужой набор себе.
- Подтверждает реакцией 👍 (добавлено) / 👀 (во входящие), а не спамит сообщениями.

**Мини-апп** (кнопка меню «Наборы» или `/app`)
- Список наборов с обложками, создание нового из входящих.
- Внутри набора: перетаскивание для смены порядка, «в начало / в конец», переименование, эмодзи у каждого стикера (до 20), удаление стикера и всего набора, ссылка на набор.
- Добавление из входящих или загрузкой файла (картинки сами ужимаются до 512px; `.tgs` / `.webm` грузятся как есть).
- Переключатель «бот добавляет сюда».
- Анимированные (`.tgs`) стикеры проигрываются через lottie, видео — через `<video>` (на iOS показывается превью).

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), возьми токен.
2. Нужен публичный HTTPS-адрес до порта `8080` (свой домен за nginx/Caddy, или на время разработки `cloudflared tunnel --url http://localhost:8080` / ngrok).
3. `cp .env.example .env` и заполни `BOT_TOKEN` и `WEBAPP_URL`.
4. Запусти:

   ```bash
   docker compose up -d --build
   ```

   или без докера:

   ```bash
   python -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python -m app.main
   ```

**Windows, в один клик:** заполни в `.env` только `BOT_TOKEN`, установи `cloudflared` (`winget install --id Cloudflare.cloudflared`) и дважды кликни `start.bat`. Он сам поставит зависимости при первом запуске, поднимет туннель, впишет свежий адрес в `WEBAPP_URL` и запустит бота. Закрыл окно — всё остановилось.

При старте бот сам выставляет команды и кнопку меню с мини-аппом. Бот работает на long polling, вебхук не нужен — HTTPS нужен только для мини-аппа.

## Устройство

- `app/service.py` — вся работа с Bot API (создание/добавление/порядок/эмодзи/удаление, ретраи на флуд-лимиты). Используется и ботом, и API.
- `app/bot.py` — хендлеры aiogram 3.
- `app/web.py` — aiohttp API для мини-аппа. Авторизация — проверка подписи `initData` от Telegram. Картинки стикеров отдаются через подписанный прокси `/f/<file_id>`.
- `app/db.py` — SQLite: наборы, активный набор юзера, входящие, полный список эмодзи (Bot API отдаёт только один).
- `webapp/` — сам мини-апп, ванильный JS + SortableJS + lottie.

Содержимое наборов не дублируется в базе — оно каждый раз читается из Telegram (`getStickerSet`), так что правки через @Stickers тоже видны. Если набор удалили снаружи, бот его забывает.

## Ограничения Telegram

- В наборе максимум 120 стикеров, название до 64 символов.
- Бот видит только наборы, которые создал сам.
- Гифки/видео из чата не конвертируются — нужен готовый `.webm` по требованиям Telegram.
